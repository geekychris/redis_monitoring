Create me a service that is able to monitor changes to redis keys.  The idea is that a client such as a react UI can render a set of simple metric components that watch for changes to redis keys.  The react UI is configurable to provide a grid of metrics.  These metrics are simple redis keys that can be subscribed to.  These could be time series metrics or simple counters or gauges.  A ui is driven from a configuration that defines the keys and the type of simple visualization.  This project should instantiate a redis instance.  Implement a backend service to subscribe to a set of keys on behalf a client.  Implement a client in react.  The react client needs to have its components defined by some kind of key to metric ui widget configuration.  Include some example metrics and something that can generate synthetic data for redis.  You can ask questions to help clarify the requirements.  The backend can be a springboot service.
